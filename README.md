# oaqjp-final-project-emb-ai

AI-Based Web Application for Emotion Detection

## Project Description
This project is an AI-powered emotion detection web application that uses Watson NLP to analyze emotions from text input.

The application detects emotions such as:
- Joy
- Anger
- Sadness
- Fear
- Disgust

## Technologies Used
- Python
- Watson NLP
- Flask
- HTML
- JavaScript

## Project Purpose
The purpose of this project is to create and deploy an emotion detection web application that analyzes user text and displays detected emotions.
